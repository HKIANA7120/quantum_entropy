📖 양자역학 및 정보 엔트로피 이론 가이드

1. 디코히어런스 노이즈 (Decoherence, η)

P(x,y) = (1 - η)·|ψ|² + η·(1/2)

양자계가 외부 환경(열, 전자기 요동 등)과 상호작용하면서 고유한 양자 결맞음(Coherence)을 잃어버리는 물리적 과정입니다. η = 0이면 순수 파동함수의 간섭성이 100% 보존되고, η = 1이 되면 완전한 열적 무작위성(순수 동전 던지기 상태)으로 붕괴됩니다.

2. 공간 파수 (kx) & 위상 편향 (φq)

θ = (x + y)·k_x + q·φ_q

- 파수 (Wavevector kx): 파동함수의 공간적 진동 빈도입니다. 값이 클수록 공간 내에서 확률 밀도 줄무늬가 더 촘촘하고 복잡하게 나타납니다.
- 위상 편향 (φq): 4개의 큐비트 q ∈ {0,1,2,3} 사이에 주어지는 고유한 위상 엇갈림으로, 각 비트 간의 상관관계와 16개 상태의 출현 양상을 변화시킵니다.

3. 보른의 규칙 (Born's Rule)

|ψ|² = cos²(θ)

양자역학에서 파동함수 ψ의 확률 진폭의 절댓값 제곱이 곧 해당 상태로 관측될 확률이라는 기본 원리입니다. 본 시뮬레이터에서는 각 위치 (x,y)에서 큐비트가 |1⟩로 붕괴될 관측 확률로 작동합니다.

4. 섀넌 엔트로피 (Shannon Entropy, S)

S = - Σ p_i · log₂(p_i)   [0 ≤ S ≤ 4.0 bit]

16개 상태($2^4 = 16$)의 확률 분포가 지닌 정보 불확실성을 나타냅니다. 어느 한 상태만 집중적으로 나타나면 S = 0이 되고, 모든 상태가 균등하게 무작위로 나타나면 최대치인 S = log₂(16) = 4.0 bit에 수렴합니다.

5. 상태 순도 (State Purity, γ)

γ = Σ (p_i)²   [1/16 ≤ γ ≤ 1.0]

양자 밀도 행렬의 대각합 Tr(ρ²)과 일치하는 지표입니다. 계가 하나의 단일 순수 상태(Pure State)에 집중될 때 γ = 1.0이 되며, 완전 혼합 상태(Completely Mixed State)에서는 최솟값인 1/16 = 0.0625가 됩니다.

6. 엔트로피와 양자역학의 상관관계 요약

양자 결맞음이 온전히 유지될 때(낮은 노이즈), 공간적 간섭으로 인해 특정 상태들만 선택적으로 생성되므로 엔트로피는 낮고 순도는 높게 유지됩니다. 반대로 환경 노이즈(디코히어런스)가 유입되면 정보가 환경으로 유출되어 엔트로피가 극대화됩니다.
